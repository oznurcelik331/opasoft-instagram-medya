# Opa Soft — Instagram medya

Bu depo @opasoft.tr Instagram hesabında herkese açık paylaşılacak görsel ve videoları barındırır.
Instagram API medyayı herkese açık bir adresten çektiği için dosyalar burada durur.

- `medya/` — gönderiler, carousel, Reels videoları ve kapaklar
- `takvim.json` — paylaşım takvimi (yalnızca zaten herkese açık olacak açıklamalar)
